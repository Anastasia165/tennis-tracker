# Правила работы с секретами

- Не читать, не изменять и не копировать содержимое файлов с именем `.env` в этом проекте, включая `tennis_tracker/.env`. Если `.env` используется как каталог, правило распространяется на всё его содержимое.
- Не извлекать эти данные косвенно: через поиск, терминал, Python/Node, импорт настроек, переменные окружения, отладчик, журналы, IDE-контекст, изображения экрана, MCP или другие инструменты.
- Не пытаться обходить запрет, менять права для чтения секретов или запрашивать повышение разрешений ради их чтения.
- Не запускать `bot.py`, `identify.py` или диагностику, которая загружает настоящий `.env`. Пользователь запускает такие команды самостоятельно.
- Для разработки использовать `.env.example` только с фиктивными значениями и тесты с искусственными данными. Не запрашивать у пользователя токены и пароли.
- Если задача зависит от секретной настройки, дать пользователю команду для самостоятельной проверки и запросить только несекретный результат.
